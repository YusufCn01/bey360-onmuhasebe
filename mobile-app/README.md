# Bey360 Mobile App

Bu klasör Bey360 için Expo tabanlı mobil uygulama başlangıcıdır.

## Çalıştırma

```bash
cd mobile-app
npm start
```

## Yerel API ayarı

`.env` dosyası oluşturup aşağıdaki alanı düzenleyin:

```env
EXPO_PUBLIC_API_BASE_URL=http://192.168.0.18:3000
```

Telefon testi için cihazın aynı Wi-Fi üzerinde olması gerekir.
